# 일 잘하는 강프로

개인 또는 4~5명 소규모 팀이 쓰는 **업무 기억 보조 도구**.
잊기 쉬운 업무를 다시 떠올리게 하는 것이 전부입니다.

들어가려면 **팀 암호**가 필요합니다. 암호 없이는 아무것도 보이지 않습니다.

## 열어보기

폴더째 받아서 `index.html`을 더블클릭하면 됩니다.
**파일 하나만 따로 열면 디자인이 안 입혀집니다.** `assets` 폴더가 옆에 있어야 합니다.

혼자서도 열리는 파일이 필요하면 `preview.html`을 쓰십시오.

## 고치는 곳

| 하고 싶은 것 | 고칠 파일 |
|---|---|
| 메뉴 추가·이름 변경 | `assets/site.js`의 `SITE` |
| 색·글씨·여백 | `assets/style.css`의 `:root` |
| 메인 화면 블록 | `assets/home.js` |
| "3일 뒤" 같은 말 인식 | `assets/when.js` |
| 업무 도구 추가 | `tool-이름.html` + `assets/tools.js` |

원본을 고친 뒤 미리보기 파일을 다시 만들려면:

```bash
python tools/build-preview.py
```

VS Code에서는 `Ctrl+Shift+B`로도 실행됩니다.

## 배포

**저장소는 비공개입니다.** 내부 업무 내용이 들어가므로 공개로 되돌리지 마십시오.

Cloudflare Pages에서 `main` 브랜치를 봅니다. 빌드 명령은 없습니다(정적 파일).
push하면 1~2분 뒤 반영됩니다.

> 저장소가 비공개여도 **배포된 주소는 누구나 열 수 있습니다.**
> 팀 암호는 업무·불편사항 같은 **데이터**만 막아줍니다.
> `tool-*.html`의 글자는 그대로 보이니 회사명·고객사명은 소스에서도 빼십시오.

## 만들 때 지킨 것

- 회사명·고객사명은 소스에 넣지 않습니다.
